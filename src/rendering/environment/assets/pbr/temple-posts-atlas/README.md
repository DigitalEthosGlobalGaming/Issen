# temple-posts-atlas PBR pack

Generated from [temple-posts-atlas.png](../../temple-posts-atlas.png) with `wood`, Sprite/OpenGL.

Six aligned 2172×724 maps: diffuse, normal, roughness, metallic, AO and emissive. Original diffuse alpha is retained.

Maps: [diffuse](temple-posts-atlas_diffuse.png), [normal](temple-posts-atlas_normal.png), [roughness](temple-posts-atlas_roughness.png), [metallic](temple-posts-atlas_metallic.png), [ao](temple-posts-atlas_ao.png), [emissive](temple-posts-atlas_emissive.png).

Exact settings and provenance: [generation.json](generation.json).

Generated and installed; renderer lighting is not connected by this pack. Visual review is pending. Source artwork is unchanged.

This is a material starting point. Mixed artwork uses the dominant preset; individual material regions may need refinement before wiring.

Exports passed ZIP integrity, dimensions, applied-setting and diffuse-alpha checks. See [PBR tool instructions](../../../../../../scripts/pbr/README.md).
