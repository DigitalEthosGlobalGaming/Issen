# issen-logo PBR pack

Generated from [issen-logo.png](../../issen-logo.png) with `default`, Sprite/OpenGL.

Six aligned 600×400 maps: diffuse, normal, roughness, metallic, AO and emissive. Original diffuse alpha is retained.

Maps: [diffuse](issen-logo_diffuse.png), [normal](issen-logo_normal.png), [roughness](issen-logo_roughness.png), [metallic](issen-logo_metallic.png), [ao](issen-logo_ao.png), [emissive](issen-logo_emissive.png).

Exact settings and provenance: [generation.json](generation.json).

Generated and installed; renderer lighting is not connected by this pack. Visual review is pending. Source artwork is unchanged.

This is a material starting point. Mixed artwork uses the dominant preset; individual material regions may need refinement before wiring.

Generated reference maps; this artwork is not automatically a physical material or a lit surface.

Exports passed ZIP integrity, dimensions, applied-setting and diffuse-alpha checks. See [PBR tool instructions](../../../../../scripts/pbr/README.md).
