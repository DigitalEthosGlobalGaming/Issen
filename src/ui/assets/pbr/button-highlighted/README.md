# button-highlighted PBR pack

Generated from [button-highlighted.png](../../button-highlighted.png) with `cloth`, Sprite/OpenGL.

Six aligned 128×128 maps: diffuse, normal, roughness, metallic, AO and emissive. Original diffuse alpha is retained.

Maps: [diffuse](button-highlighted_diffuse.png), [normal](button-highlighted_normal.png), [roughness](button-highlighted_roughness.png), [metallic](button-highlighted_metallic.png), [ao](button-highlighted_ao.png), [emissive](button-highlighted_emissive.png).

Exact settings and provenance: [generation.json](generation.json).

Generated and installed; renderer lighting is not connected by this pack. Visual review is pending. Source artwork is unchanged.

This is a material starting point. Mixed artwork uses the dominant preset; individual material regions may need refinement before wiring.

Exports passed ZIP integrity, dimensions, applied-setting and diffuse-alpha checks. See [PBR tool instructions](../../../../../scripts/pbr/README.md).
